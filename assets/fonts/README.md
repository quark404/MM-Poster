# Poster fonts

- **Comic Neue Bold**: rounded handwritten headings. Source: https://github.com/google/fonts/tree/main/ofl/comicneue . SIL Open Font License in `ComicNeue-OFL.txt`.
- **Open Sans Regular / Bold**: body copy and tables. Included system font distribution, license and provenance in `OpenSans-LICENSE.txt`.

Install the three `.ttf` files before editing the PPTX to preserve the intended typography. PDF and standalone HTML embed these fonts and do not need a local installation. The fonts approximate the reference style; the exact typeface used in the supplied reference cannot be identified reliably from its screenshot.
